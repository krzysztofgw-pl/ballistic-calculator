# Bullet library

`app/src/main/resources/bullets.csv` is generated by `build_library.py`:

```bash
python3 tools/bullet-library/build_library.py \
  tools/bullet-library/ammolytics-projectiles.csv \
  tools/bullet-library/berger-2024.csv \
  app/src/main/resources/bullets.csv
```

Sources, later ones overriding earlier ones for the same maker, name, caliber and weight:

1. `ammolytics-projectiles.csv`: the open
   [ammolytics/projectiles](https://github.com/ammolytics/projectiles) dataset (MIT, see
   `LICENSE-ammolytics`, commit 5b51ab2), compiled from Barnes, Hornady, Lapua and Speer
   catalogue pages. Its Berger and Sierra rows are not used: Berger comes from the newer catalogue
   below and the dataset has no Sierra BCs.
2. `berger-2024.csv`: the Berger 2024 catalogue, with length and minimum twist.
3. A short curated list in the script with current manufacturer figures that differ from or are
   missing in the dataset (Hornady ELD Match and ELD-X revisions, Sierra MatchKing).

Only rifle bullets with at least one published BC are kept. BCs are the manufacturers' published
figures in lb/in²; they change over time, so check them against the current catalogue.

To add or correct a bullet, edit the source CSV or the curated list and run the script again.
